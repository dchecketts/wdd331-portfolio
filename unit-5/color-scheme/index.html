The root scheme also changes the default page canvas. This page does not set a background color on html or body.

System colors let custom elements match the native palette without hard-coded color values.

Native controls and scrollbar appearance vary by browser and OS. Overlay scrollbars may only appear while scrolling.

The key CSS

:root { color-scheme: light dark; }

html:has([name="theme"][value="light"]:checked) {
    color-scheme: light;
}

html:has([name="theme"][value="dark"]:checked) {
    color-scheme: dark;
}

.native-card {
    background: Field;
    color: FieldText;
}

The head also includes <meta name="color-scheme" content="light dark"> before the stylesheet so the browser can choose an appropriate initial canvas before CSS loads.
