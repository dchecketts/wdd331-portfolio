04 / The email invitation

Same measure. Different font.

Demonstrate: set the measure to 35ch, switch fonts, then increase the text size. Compare the rendered width in pixels. Watch the square beside the lowercase letters scale with the font’s x-height.

45ch 20px

xxxxx · a marker sized in ex

Your next idea does not have to start on a blank page. Join us at open studio to trade feedback, ask a small question, or try a completely different direction. We will have space to spread out, a few short activities, and time to work on whatever you bring.

The sample uses a maximum width in ch. Available space can limit the width. A ch measures the advance of “0”; it counts equal-width characters in monospace, rather than arbitrary letters in a proportional font.

.invitation { max-inline-size: 45ch; font-size: 20px; }
.marker { inline-size: 1ex; block-size: 1ex; }
