Box sizing

The default content-box model adds padding and borders outside the declared width.

Comparing box-sizing values

Content box

Padding and border are added to the declared width.

Border box

Padding and border are included in the declared width.

Summary

  • min-width: 0 allows a flex item to shrink horizontally.
  • min-height: 0 allows a column flex item to shrink vertically.
  • box-sizing: border-box includes padding and borders in the declared width.
